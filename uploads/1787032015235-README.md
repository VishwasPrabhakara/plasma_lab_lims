# AquaTrace LIMS

A working water laboratory LIMS website with backend and frontend.

## Run

1. Open a terminal in this folder.
2. Run `npm start`.
3. Open `http://localhost:4317`.

Default admin login:

- Email: `admin@lab.local`
- Password: `admin123`

## Main Workflow

1. Login as admin.
2. Add people, storage locations, and test methods from **People & Storage**.
3. Register a new sample from **New Sample**.
4. Print or scan the generated QR label from the sample detail page.
5. Use **Book Upload** to attach the written lab book page, photo, scan, or PDF.
6. Use **Result Sheet** to type values row by row into the sample's analysis sheet.
7. Use **Paste Import** only when copying rows from Excel or instrument text.
8. Use **Saved Results** to review values already saved to the sample.
9. A manager or admin approves results.
10. All important changes remain in the **Audit** page.

## Book Upload vs Sheet Entry

- **Book Upload** is for the written record: scanned page, phone photo, PDF, or lab-book evidence.
- **Result Sheet** is for structured results: parameter, value, unit, limit, method, and flag.
- Both remain linked to the same sample ID and QR code.
- Neither workflow deletes earlier data; new actions are added and audited.

## Roles

- `admin`: full access, user creation, approval
- `manager`: master data, sample modification, approval
- `analyst`: result entry and uploads
- `intake`: sample registration and uploads
- `viewer`: read-only access

The system has no delete button. Data is modified and audited instead of deleted.

## Stored Data

- Main database: `data/db.json`
- Uploaded files: `uploads/`
- Browser mirror cache: local browser storage

For online use, host this same app on a server and back up `data/db.json` plus `uploads/`, or replace the JSON store with PostgreSQL/MySQL.
