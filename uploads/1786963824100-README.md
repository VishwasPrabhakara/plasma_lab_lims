# AquaTrace LIMS

A working water laboratory LIMS website with backend and frontend.

## Run

1. Open a terminal in this folder.
2. Run `npm start`.
3. Open `http://localhost:4317`.

Default admin login:

- Email: `admin@lab.local`
- Password: `admin123`

## Main Workflow

1. Login as admin.
2. Add people, storage locations, and test methods from **People & Storage**.
3. Register a new sample from **New Sample**.
4. Print or scan the generated QR label from the sample detail page.
5. Enter analysis values in the **Results** tab.
6. Upload lab book photos, instrument data, worksheets, chain-of-custody files, or final reports from the **Uploads** tab.
7. A manager or admin approves results.
8. All important changes remain in the **Audit** page.

## Roles

- `admin`: full access, user creation, approval
- `manager`: master data, sample modification, approval
- `analyst`: result entry and uploads
- `intake`: sample registration and uploads
- `viewer`: read-only access

The system has no delete button. Data is modified and audited instead of deleted.

## Stored Data

- Main database: `data/db.json`
- Uploaded files: `uploads/`
- Browser mirror cache: local browser storage

For online use, host this same app on a server and back up `data/db.json` plus `uploads/`, or replace the JSON store with PostgreSQL/MySQL.
